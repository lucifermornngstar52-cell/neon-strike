# NEON STRIKE

Браузерный 3D FPS на Three.js — бесконечные волны роботов в неоновой арене.

## Играть
https://lucifermornngstar52-cell.github.io/neon-strike/

## Управление
### ПК
- **ЛКМ** — стрелять
- **WASD** — движение, **SHIFT** — спринт, **SPACE** — прыжок
- **R** — перезарядка, **ESC** — пауза
- Хедшот = двойной урон

### Мобильные (тач)
- **Слева стик** — движение (до упора = спринт)
- **Правая половина экрана** — свайп = камера
- **Кнопки**: ОГОНЬ, прыжок ▲, перезарядка ⟳, пауза II
- Аим-ассист включён
